% Provisional MAUS Parameter Set for Hungarian 
% 
% This set uses HMMs trained on the BEA corpus (45) and cloned acoustical models 
% from the German parameter set (21).
% 
% BEA trained HMM added on 2015-03-03.
% 
% Some additional phoneme classes added by mapping them to existing HMMs,
% e.g. T for English words etc.
% 
% BEA based pronuciation rule set added HUNGARIAN.smooth.prune20.rul.
% This rule set was trained on the (rather messy) alignment of the 
% BEA phonetic annotation to G2P produced phonological pronunciation.
% Only rule instances that were obeserved more than 20 times in the BEA
% corpus (41986 words) were considered (144 basic rules). Context smoothing
% of these rules expanded the set to 2885 rules. 
% For usage of a rule set without context smoothing use maus option 
% RULESET=HUNGARIAN.nosmooth.prune20.rul etc. 
% 
% See also the file USAGE in the top directory of the package.
% 
% Thanks to Gyarmathy Dorottya, MTA Nyelvtudományi Intézet, for providing the 
% access to the Hungarian BEA corpus.
