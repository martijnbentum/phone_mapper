% See also the file USAGE in the top directory of the package.

% This is the parameter set of Scottish English MAUS (eng-SC). 
% Acoustic models and pronunciation model were trained to the Scottish,
% manually segmented part of the International Corpus of English (ICE).
% See the report of CLARIN F-AG 6 (2016) for details of this curation).
% 
% Data were compiled by Lukas Steinbauer; for details see his BA thesis (2017).
% 
% The pronunciation model expects eng-GB canonical input, i.e. if you are
% using G2P to create the canonical phonological form, use -lang eng-GB.
% Caused by this the rule sets contain 'replacement' rules with conditional
% probability 1, indicating a replacement of a canonical British sound by 
% a Scottish sound.
% 
% Bug report: the rule set rml.prune10smooth.rul.defunct is faulty (= can cause an error
% maus) because the sum over the conditional probs are for some rule contexts
% greater than 1 (what cannot be). The (default) 20 and 50 sets are ok.
