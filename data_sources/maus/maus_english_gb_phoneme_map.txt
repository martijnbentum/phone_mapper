% English standard SAM-PA inventar (Wells) extended by:

% Acoustic modeling with British English HMM trained on a manually transcribed 
% corpus AIX-MARSEC kindly provided by David Hirst.
% - 3 nasalized vowels /a~/, /E~/ and /o~/ are included to allow the 
% processing of French words (not trained but mapped to non-nasalized vowels).
% - HMMs /x/ and /?/ not trained in corpus but cloned from German set
% 
% Pronunciation modelling trained on the manually transcribed
% corpus AIX-MARSEC kindly provided by David Hirst. This corpus contains a 
% forced time-alignment that utilizes varying pronunciation variants. It follows 
% that the MAUS pronunciation model reflects most of these variants but no other 
% processes since no manual phonetic segmentation was performed on the 
% AIX-MARSEC corpus.
% Nevertheless, we think that the transcription is good enough for a pronunciation 
% model to cover the most frequent phonetic processes in British English. The 
% trained rule set (without context smoothing, rule pruning = 10) contains 
% 167 rules.
% 
% Both, the acoustical and pronunciation model was developped by Ines Wendler from 
% Munich. Thank you very much for that important contribution. 
% 
% See also the file USAGE in the top directory of the package.
