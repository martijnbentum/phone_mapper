% MAUS Parameter Set for ITALIAN
% 
% This PARAM set can be used to apply MAUS to Italian input. 
% 
% HMM sets:
% 
% 1. isoreesthmm_ITALIAN.mmf :
% Acoustic models are mapped to models trained on German. 
% The inventar follows the standard SAMPA inventar for Italian.
% Geminates are modelled by single acoustical models, since geminates 
% dominatly change the length of the phoneme only in Italian.
% e.g.  /dd/  is modelled by /d/
% but in the result one segment named /dd/ is produced.
% /r/ is modelled by /d/ (tap) and /rr/ by /r/.
% The following phoneme symbols have been added to allow a rudimentary
% handling of French, German and English forein words:
% English : aI aU eI OI @U T D @
% French  : e~ E~ a~ o~ @
% German  : y: 2: Y 9 6 @
% 
% 2. CLIPS_MT.mmf (default) :
% HInit training on manually labelled part of the CLIPS Map Task 
% corpus. Thanks to Francesco Cutugno and his colleagues.
% Italian SAM-PA Italian set with extensions:
% English : T D @
% French  : e~ E~ a~ o~ @
% German  : ? y: 2: @
% Some glide-vowel combinations/diphthongs, since they were labelled and 
% segmented as such in the CLIPS corpus (and they mostly make sense):
% ue,oi,Oi,oE,io,ei,Ei,ai,ja,jo,ju,wa,we,wi,wO
% This can be a problem if you want MAUS to segment for instance /wi/
% in two segments /w i/. In this case try to insert a blank into the 
% input KAN tier, e.g. 'sedj a'.
% Furthermore the phoneme set contains not only the standard plosives 
% (e.g. /d/) and their geminates (e.g. /dd/) but also models for 
% closure and release for each plosive (e.g. /d_cl/ and /d_rl/). 
% However note that the Italian rule set (see below) will not deal with these
% closure/release models (there are no rules for these) and simply pass 
% them through.
% After a major re-work og the MT part of CLIPS in Dec 2013 where tons of errors were
% fixed we ran a new HMM training on CLIPS (20131227). Unfortunately the 
% results did not improve but rather deteriorated (mistery!). Therefore the
% current HMM version is 20131228, which is effectively the previous version.
% 
% Rule sets:
% 
% Based on the phonolgical annotation (*.std files) and phonetic annotation 
% (*.phn files) of the Italian CLIPS Map Task corpus (47341 words), several MAUS rule sets were 
% trained automatically using the tool maus.learn (no part of the distribution).
% Depending on pruning level (the minimum number of observed events for a phonological 
% rule) and smoothing technique (nosmooth : plain rules; smooth : left/right contexts
% expanded to similar phonemes of Italian) several rule set for Italian MAUS 
% were created (see below). Since no validation set for ITALIAN exists (yet), we 
% cannot determine which of these sets are optimal for using Italian MAUS; it 
% is very likely that this also depends on what kind of input speech the Italian MAUS
% is applied to (e.g. read speech might require less and more strict rule sets while 
% spontaneous speech might benefit from larger rule sets). All rule sets handle
% SAM-PA symbols of Italian only, that is no sub-phoneme events such as /t_cl/ and /t_rl/
% are treated by the rule sets (if they occur in the input, they are simply passed through 
% the variant graph generation stage of MAUS): 
% 
% ITA.nosmooth.prune4.rul : basic rule set, pruning threshold >4 events (588 rules)
% ITA.nosmooth.prune10.rul : basic rule set, pruning threshold >10 events (241 rules)
% ITA.nosmooth.prune20.rul : basic rule set, pruning threshold >20 events (121 rules)
% ITA.nosmooth.prune50.rul : basic rule set, pruning threshold >50 events (24 rules)
% ITA.smooth.prune10.rul : context smoothed rule set, pruning threshold >10 events (1787 rules)
% ITA.smooth.prune20.rul : context smoothed rule set, pruning threshold >20 events (764 rules, default)
% ITA.smooth.prune50.rul : context smoothed rule set, pruning threshold >50 events (117 rules)
% 
% In general increased pruning will make the rules more robust but less coverage. Smooting will
% transfer the observed events to other left-right contexts; this may result in rules that 
% make no sense phonologically, but was found to improve the generalisation of the rule set.
% 
% The rule set:
% ITA.nosmooth.noprune.rul (2788 rules)
% is a collection of all empirical rule events we found in the CLIPS corpus, and can be 
% used as a starting point to procuded rule sets with differing pruning techniques as the ones
% listed above. The fourth column gives the total occurance count, e.g. the rule entry
% 
% tS,E,n>tS,e,n -0.762140 0.000000 21
% 
% means that the replacement of /E/ by /e/ in the context tS _ n
% was found 21 times in the CLIPS Map Task corpus, and that the 
% conditional probability P(tS,e,n|tS,E,n) = 0.173.
% The fifth column is a list of comma-separated source strings of recordings
% in which the rule was found.
% 
% 
% See also the file USAGE in the top directory of the package.
%
