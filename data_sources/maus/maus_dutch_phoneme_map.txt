% ----------------------------------------------------------------------------------------
% 
% MAUS Parameter Set nld-NL
% 
% This parameter set is adapted for Dutch spoken in Northern Netherlands. 
% It uses the standard Dutch SAM-PA inventar extended by glottal stop (although not defined 
% in the official Dutch SAMPA set) as well as some French, German and 
% English phonemes to allow foreign word segmentation.
% 
% Acoustic models are trained on the manually verified phonetic transcriptions
% (fn*.fon) of the CGN corpus using maus.iter; phoneme symbols of CGN were adapted to match SAM-PA.
% The pronunciation model is trained on the same corpus with reference to 
% G2P using lng = nld-NL. Due to systematic differences in the way CGN encoded
% canonic pronunciation and the way G2P translated nld-NL, there are a small number 
% of replacement rules (with prob = 1.0) which were changed so that the conditional
% prob is 0.5 (so effectively both, the G2P and CGN variants, are equally probable).
% 
% 
% See also the file USAGE in the top directory of the package.
%
