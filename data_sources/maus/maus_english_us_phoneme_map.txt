% Provisional MAUS Parameter Set AMERICAN ENGLISH
% 
% This parameter set uses acoustic models (HMM) trained in the 
% TIMIT speech corpus (TEST+TRAIN!) and a probabilistic 
% rule set trained from the same data set (54384 words).
% 
% - The phoneme set is the (translated) TIMIT phone set extended by a couple 
% of missing SAM-PA definitions for general English that were not used in TIMIT:
% A:,I@,e@,U@,3:,e. The latter are modelled by Australian speech data.
% - several rule sets are available trained on the TIMIT transcription with reference
% to the TIMIT pronunciation dictionary (*.rul). 'nosmooth/smooth' regards to the use 
% of context smoothing; 'pruneXX' regards to absolute count pruning, i.e. 'prune20' means that 
% a pronunciation rule must be observed at least 21 times in the data. An informal evaluation
% on TIMIT data revealed that smoothing does not improve results (this may be not the case for data 
% from other sources) but also not deteriorates results; the best results were achieved with 
% a absolute count pruning of 5; therefore we set the default rule set to TIMIT.smooth.prune5.rul.
% - weighting between acoustics and top-down prediction of pronunciation was set to 10.0 (option 
% WEIGHT, see file DEFAULTS); this implies that top-down information is rather important for American
% English; for data from other sources this value of WEIGHT might be lowered to be optimal.
% - 3 nasalized vowels /a~/, /e~/ and /o~/ (taken from the German phone set) 
% are included to allow the processing of French words.
% 
% History:
% 
% 2014-10-07 : first conversion of TIMIT
% 2014-12-12 : fixed bug in legacy Emu files: phonetic layer contained 'combined'
% segements formed from sub-segmentals on the vot layer, but a large number of these were
% 'combinations' of sub-segmentals of different label class (e.g. p_cl + t -> p). The new version
% only combines sub-segmentals on layer phonetic if they are of the same class (e.g. b_cl + b -> b).
% Since the BPF and TextGrids also contain combined segments but these are labelled with the
% label of the second segment (e.g. p_cl + t -> t) the phonetic layer and the SAP layer differ!
% The par and TextGrid files were not changed in this update; therefore no new rule training
% has been applied.
% 2016-12-19 : changed the (MAUS internal) label definition from /h-/ back to /h\/ (X-SAMPA)
% 2018-10-02 : there is a problem with the eng-US rule sets trained on TIMIT: it seems that the 
% rule sets with pruning = 5 contain so called 'replacement rules' with a ln() = -0.000001 that 
% effectively always apply to the left-hand context of the rule. word_var-2.0 sometimes crashes,
% when such a context appears in the input. Since I could not figure out what the proble is 
% (the rules look perfectly normal), I replaced the ln() = -0.000001 by a lower probability, and then 
% the error vanished. A lower prob. than 1.0 for a rule makes sense anyway, since the acoustics 
% should in the end decide whether the replacement is applicable.
% Changed both rule sets with pruning = 5 accordingsly; copies of the old versions are retained
% in files *.20181002
%  
% 
% See also the file USAGE in the top directory of the package.
%
